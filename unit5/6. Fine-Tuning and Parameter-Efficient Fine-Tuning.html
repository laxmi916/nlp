Fine-Tuning and Parameter-Efficient Fine-Tuning

A pretrained Transformer already knows general language patterns. Fine-tuning adapts that pretrained model to a specific task or domain using a smaller task-specific dataset. 

Pretrained Transformer
        ↓
Task-Specific Dataset
        ↓
Fine-Tuning
        ↓
Specialized Model

1. Why Fine-Tune a Pretrained Model?

Training a Transformer from scratch requires enormous amounts of data and computational resources. Fine-tuning starts with an existing pretrained model and teaches it a particular task.

Pretrained Model Fine-Tuned Model
General language knowledge Task-specific knowledge
Large general dataset Usually smaller task dataset
Expensive to train from scratch Much cheaper than pretraining
General-purpose Specialized

2. Full Fine-Tuning

In traditional fine-tuning, the pretrained model's parameters are updated during training. 

Pretrained Model
      ↓
Input
      ↓
Transformer
      ↓
Prediction
      ↓
Loss
      ↓
Backpropagation
      ↓
Update many/all model parameters

For a large language model, updating billions of parameters can require substantial GPU memory, storage, and training time.

3. Example — Fine-Tuning DistilBERT for Classification

We can fine-tune a pretrained DistilBERT model for a small binary classification task.

Install the required libraries:

pip install torch transformers datasets


import torch

from datasets import Dataset

from transformers import (
    AutoTokenizer,
    AutoModelForSequenceClassification,
    TrainingArguments,
    Trainer
)


# --------------------------------------------------
# 1. Small training dataset
# --------------------------------------------------

data = {
    "text": [
        "I really enjoyed this movie.",
        "This movie was excellent.",
        "I hated this movie.",
        "This movie was terrible."
    ],

    "label": [
        1,
        1,
        0,
        0
    ]
}


dataset = Dataset.from_dict(data)


# --------------------------------------------------
# 2. Load pretrained model
# --------------------------------------------------

model_name = "distilbert-base-uncased"

tokenizer = AutoTokenizer.from_pretrained(
    model_name
)


# --------------------------------------------------
# 3. Tokenize the dataset
# --------------------------------------------------

def tokenize_function(example):

    return tokenizer(
        example["text"],
        truncation=True,
        padding="max_length",
        max_length=64
    )


tokenized_dataset = dataset.map(
    tokenize_function
)


# --------------------------------------------------
# 4. Load classification model
# --------------------------------------------------

model = AutoModelForSequenceClassification.from_pretrained(
    model_name,
    num_labels=2
)


# --------------------------------------------------
# 5. Training configuration
# --------------------------------------------------

training_args = TrainingArguments(
    output_dir="./fine_tuned_model",

    num_train_epochs=3,

    per_device_train_batch_size=2,

    learning_rate=5e-5,

    logging_steps=1,

    save_strategy="no"
)


# --------------------------------------------------
# 6. Trainer
# --------------------------------------------------

trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=tokenized_dataset
)


# --------------------------------------------------
# 7. Fine-tune
# --------------------------------------------------

trainer.train()


# --------------------------------------------------
# 8. Save model
# --------------------------------------------------

trainer.save_model(
    "./fine_tuned_model"
)

tokenizer.save_pretrained(
    "./fine_tuned_model"
)


print("Fine-tuning completed.")

The important idea is that the pretrained DistilBERT parameters are updated using the new classification examples.

4. Limitations of Full Fine-Tuning

For a very large model, full fine-tuning can become expensive. 

Large Model
     ↓
Billions of parameters
     ↓
Large GPU memory requirement
     ↓
Large optimizer states
     ↓
Large training cost

This motivates Parameter-Efficient Fine-Tuning (PEFT).

Parameter-Efficient Fine-Tuning (PEFT)

5. What is PEFT?

Parameter-Efficient Fine-Tuning (PEFT) adapts a pretrained model while training only a small number of additional or selected parameters. 

Pretrained Model
       ↓
Keep most parameters frozen
       ↓
Train a small number of parameters
       ↓
Specialized Model

The goal is to obtain much of the benefit of fine-tuning while reducing trainable parameters and computational requirements.

6. LoRA

LoRA (Low-Rank Adaptation) is one of the most widely used PEFT techniques.

Instead of directly changing a large pretrained weight matrix, LoRA keeps the original weights frozen and learns a small low-rank update.

Conceptually: 

Original weight:

W

LoRA learns:

ΔW = B × A

Updated weight:

W' = W + ΔW

where A and B are much smaller matrices than the original weight matrix.

7. Why is LoRA Efficient?

Full Fine-Tuning

Large W
 ↓
Update all parameters


LoRA

Large W
 ↓
Freeze W

Small A + B
 ↓
Train only A and B

Therefore, the number of trainable parameters can be dramatically reduced.

8. LoRA Architecture

                    Input
                      │
                      ▼
              ┌───────────────┐
              │ Frozen W      │
              │ Pretrained    │
              │ Weight        │
              └───────┬───────┘
                      │
                      │
Input ──────► LoRA A ─► LoRA B
                      │
                      ▼
                 Small Update
                      │
                      ▼
                W + ΔW
                      │
                      ▼
                   Output

9. LoRA Parameters

LoRA commonly uses a small integer called rank (r) to control the size of the low-rank matrices. 

Large Matrix W
     │
     │
     ├── LoRA rank r = 4
     │
     ├── LoRA rank r = 8
     │
     └── LoRA rank r = 16

A smaller rank means fewer trainable parameters, while a larger rank gives LoRA more capacity to learn task-specific changes.

10. Example — LoRA with a Transformer

The Hugging Face PEFT library provides an easy way to add LoRA adapters to a pretrained Transformer.

Install the required libraries:

pip install torch transformers peft


import torch

from transformers import (
    AutoTokenizer,
    AutoModelForSequenceClassification
)

from peft import (
    LoraConfig,
    get_peft_model,
    TaskType
)


# --------------------------------------------------
# 1. Load pretrained model
# --------------------------------------------------

model_name = "distilbert-base-uncased"

tokenizer = AutoTokenizer.from_pretrained(
    model_name
)

model = AutoModelForSequenceClassification.from_pretrained(
    model_name,
    num_labels=2
)


# --------------------------------------------------
# 2. Create LoRA configuration
# --------------------------------------------------

lora_config = LoraConfig(

    task_type=TaskType.SEQ_CLS,

    r=8,

    lora_alpha=16,

    lora_dropout=0.1,

    target_modules=[
        "q_lin",
        "v_lin"
    ]
)


# --------------------------------------------------
# 3. Add LoRA adapters
# --------------------------------------------------

model = get_peft_model(
    model,
    lora_config
)


# --------------------------------------------------
# 4. Display trainable parameters
# --------------------------------------------------

model.print_trainable_parameters()

The important output is a comparison between the total number of model parameters and the much smaller number of trainable parameters. 

trainable parameters: ...
total parameters: ...
trainable percentage: ...

11. Example — Training the LoRA Model

The LoRA model can be trained using the same Hugging Face training tools. Only the LoRA parameters are updated. 


from datasets import Dataset

from transformers import (
    TrainingArguments,
    Trainer
)


# --------------------------------------------------
# 1. Small dataset
# --------------------------------------------------

data = {
    "text": [
        "I loved this movie.",
        "This movie was fantastic.",
        "I hated this movie.",
        "This movie was awful."
    ],

    "label": [
        1,
        1,
        0,
        0
    ]
}


dataset = Dataset.from_dict(data)


# --------------------------------------------------
# 2. Tokenization
# --------------------------------------------------

def tokenize_function(example):

    return tokenizer(
        example["text"],
        truncation=True,
        padding="max_length",
        max_length=64
    )


dataset = dataset.map(
    tokenize_function
)


# --------------------------------------------------
# 3. Training configuration
# --------------------------------------------------

training_args = TrainingArguments(

    output_dir="./lora_model",

    num_train_epochs=3,

    per_device_train_batch_size=2,

    learning_rate=1e-4,

    logging_steps=1,

    save_strategy="no"
)


# --------------------------------------------------
# 4. Trainer
# --------------------------------------------------

trainer = Trainer(

    model=model,

    args=training_args,

    train_dataset=dataset
)


# --------------------------------------------------
# 5. Train LoRA adapters
# --------------------------------------------------

trainer.train()


# --------------------------------------------------
# 6. Save LoRA adapter
# --------------------------------------------------

model.save_pretrained(
    "./lora_model"
)

tokenizer.save_pretrained(
    "./lora_model"
)


print("LoRA fine-tuning completed.")

12. Full Fine-Tuning vs LoRA

Full Fine-Tuning LoRA / PEFT
Updates many/all pretrained parameters Updates a small number of adapter parameters
Higher memory requirement Lower memory requirement
Large model checkpoint after training Small adapter checkpoint
More expensive More parameter-efficient
Useful when extensive model adaptation is required Useful when adapting large models with limited resources

13. Fine-Tuning vs LoRA

                    Pretrained Model
                           │
              ┌────────────┴────────────┐
              │                         │
              ▼                         ▼
       Full Fine-Tuning              PEFT
              │                         │
       Update model                 Freeze most
       parameters                   parameters
                                        │
                                        ▼
                                      LoRA
                                        │
                              Train small adapters

14. Important LoRA Terms

Term Meaning
r Rank of the low-rank matrices.
lora_alpha Scaling factor applied to the LoRA update.
lora_dropout Dropout applied to the LoRA branch during training.
target_modules Model layers where LoRA adapters are inserted.
Adapter Small trainable component added to the pretrained model.

15. When Should You Use Each?

Small Model + Enough GPU
        ↓
Full Fine-Tuning can be practical


Large Model + Limited GPU
        ↓
PEFT / LoRA


Need multiple task-specific versions
        ↓
One Base Model
      +
Multiple LoRA Adapters

For example, one base model could have separate adapters for medical text, legal text, and customer support.

16. Key Takeaway

Pretrained Transformer
        ↓
Fine-Tuning
        ↓
Task-Specific Model


Pretrained Transformer
        ↓
PEFT / LoRA
        ↓
Freeze most parameters
        ↓
Train small adapters
        ↓
Task-Specific Model

Fine-tuning adapts a pretrained model to a new task. PEFT reduces the amount of the model that must be trained, and LoRA achieves this by learning small low-rank updates while keeping most pretrained weights frozen.
