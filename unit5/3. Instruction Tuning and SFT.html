Instruction Tuning and SFT

Pretraining teaches a language model general language patterns. However, a pretrained model is not necessarily optimized to follow user instructions. Instruction tuning further trains the model to respond to instructions and perform specific tasks.

1. Instruction-Following Models

An instruction-following model is a language model that has been additionally trained on examples of instructions and appropriate responses. 

Pretrained Model
       ↓
Instruction Dataset
       ↓
Supervised Fine-Tuning
       ↓
Instruction-Following Model

For example:

Instruction:
"Translate 'Good morning' into French."

Expected Response:
"Bonjour"

The model learns the relationship between the instruction and the desired response.

2. Supervised Fine-Tuning (SFT)

Supervised Fine-Tuning (SFT) is the process of further training a pretrained model using examples containing an input instruction and a desired output. 

Pretrained Model
       +
Instruction / Response Examples
       ↓
      SFT
       ↓
Instruction-Following Model

During SFT, the model generates a response, calculates the loss against the target response, and updates its parameters using backpropagation. 

Instruction
     ↓
Model
     ↓
Generated Response
     ↓
Compare with Target
     ↓
Loss
     ↓
Backpropagation
     ↓
Updated Model

3. Instruction Dataset

An instruction dataset contains examples showing the model how to perform tasks. 

[
  {
    "instruction": "What is Python?",
    "response": "Python is a programming language."
  },

  {
    "instruction": "Translate 'Hello' to French.",
    "response": "Bonjour."
  },

  {
    "instruction": "What is 2 + 2?",
    "response": "4"
  }
]

More commonly, instruction datasets contain fields such as instruction, input, and output. 

{
    "instruction": "Summarize the following text.",
    "input": "Artificial intelligence is ...",
    "output": "AI enables computers to ..."
}

4. Example — Creating a Small Instruction Dataset

Before using a large dataset, we can create a tiny dataset to understand the structure used in instruction tuning. 


dataset = [

    {
        "instruction": "What is Python?",
        "response": "Python is a programming language."
    },

    {
        "instruction": "What is AI?",
        "response": "AI enables computers to perform tasks that require intelligence."
    },

    {
        "instruction": "What is 2 + 2?",
        "response": "4"
    }

]

for example in dataset:

    print("Instruction:")
    print(example["instruction"])

    print("Response:")

    print()

5. Example — Instruction Tuning with a Small T5 Model

A small pretrained sequence-to-sequence model can be fine-tuned using instruction-response examples.

import torch

from transformers import (
    AutoTokenizer,
    AutoModelForSeq2SeqLM
)


# --------------------------------------------------
# 1. Load pretrained model
# --------------------------------------------------

model_name = "t5-small"

tokenizer = AutoTokenizer.from_pretrained(
    model_name
)

model = AutoModelForSeq2SeqLM.from_pretrained(
    model_name
)


# --------------------------------------------------
# 2. Instruction dataset
# --------------------------------------------------

instructions = [
    "translate English to French: Hello",
    "translate English to French: Good morning",
    "translate English to French: Thank you"
]

responses = [
    "Bonjour",
    "Bonjour",
    "Merci"
]


# --------------------------------------------------
# 3. Tokenize instructions
# --------------------------------------------------

inputs = tokenizer(
    instructions,
    padding=True,
    truncation=True,
    return_tensors="pt"
)


# --------------------------------------------------
# 4. Tokenize target responses
# --------------------------------------------------

targets = tokenizer(
    responses,
    padding=True,
    truncation=True,
    return_tensors="pt"
)


# --------------------------------------------------
# 5. Train for a few iterations
# --------------------------------------------------

optimizer = torch.optim.Adam(
    model.parameters(),
    lr=1e-4
)

model.train()

for epoch in range(10):

    optimizer.zero_grad()

    outputs = model(
        input_ids=inputs["input_ids"],
        attention_mask=inputs["attention_mask"],
        labels=targets["input_ids"]
    )

    loss = outputs.loss

    loss.backward()

    optimizer.step()

    print(
        "Epoch:",
        epoch + 1,
        "Loss:",
        loss.item()
    )


# --------------------------------------------------
# 6. Test the instruction-following model
# --------------------------------------------------

model.eval()

text = "translate English to French: Hello"

test_input = tokenizer(
    text,
    return_tensors="pt"
)


with torch.no_grad():

    output_ids = model.generate(
        **test_input,
        max_new_tokens=10
    )


result = tokenizer.decode(
    output_ids[0],
    skip_special_tokens=True
)


print("\nInstruction:")
print(text)

print("\nModel response:")
print(result)

This example demonstrates the basic SFT process: 

Pretrained T5
     ↓
Instruction + Target Examples
     ↓
Calculate Loss
     ↓
Backpropagation
     ↓
Update Parameters
     ↓
Fine-Tuned Model

6. Instruction Tuning vs Pretraining

Pretraining Instruction Tuning / SFT
Uses very large text collections Uses instruction-response examples
Learns general language patterns Learns to follow instructions
Usually performed before SFT Performed after pretraining
Example objective: next-token prediction Learn the desired response for an instruction

7. Key Idea

Pretraining
     ↓
"Learn language"
     ↓
Base Model
     ↓
SFT / Instruction Tuning
     ↓
"Learn to follow instructions"
     ↓
Instruction-Following Model

In simple terms: pretraining teaches a model how language works, while instruction tuning teaches the pretrained model how to respond to instructions and perform useful tasks.
