Transformer Embeddings and Semantic Similarity

Transformer models can convert sentences into dense numerical vectors called sentence embeddings. These vectors capture semantic information, allowing us to compare the meaning of different sentences.

1. Sentence Embeddings

A sentence embedding represents an entire sentence as a fixed-size numerical vector. 

Sentence
   ↓
Transformer Embedding Model
   ↓
Vector
   ↓
[0.21, -0.14, 0.73, ...]

Sentences with similar meanings tend to have embeddings that are closer together in vector space.

2. Example — Generate Sentence Embeddings

Install the required libraries:

pip install sentence-transformers


from sentence_transformers import SentenceTransformer

model = SentenceTransformer(
    "all-MiniLM-L6-v2"
)

sentences = [
    "I like machine learning.",
    "I enjoy artificial intelligence."
]

embeddings = model.encode(sentences)

for sentence, embedding in zip(
    sentences,
    embeddings
):

    print("\nSentence:")
    print(sentence)

    print("Embedding size:")
    print(len(embedding))

    print("First 10 values:")
    print(embedding[:10])

The model converts each sentence into a numerical vector. The all-MiniLM-L6-v2 model produces a 384-dimensional sentence embedding.

3. Cosine Similarity

Cosine similarity measures how similar two vectors are based on the angle between them. 

                    A · B
Cosine Similarity = ─────────
                    ||A|| ||B||

Values closer to 1 indicate that the vectors point in a similar direction, while values closer to 0 indicate less similarity.

4. Example — Calculate Cosine Similarity


from sentence_transformers import SentenceTransformer
from sklearn.metrics.pairwise import cosine_similarity

model = SentenceTransformer(
    "all-MiniLM-L6-v2"
)

sentences = [
    "I like machine learning.",
    "I enjoy artificial intelligence.",
    "The weather is very cold today."
]

embeddings = model.encode(
    sentences
)

similarity = cosine_similarity(
    [embeddings[0]],
    [embeddings[1]]
)

print(
    "Similarity between sentence 1 and 2:",
    similarity[0][0]
)

similarity = cosine_similarity(
    [embeddings[0]],
    [embeddings[2]]
)

print(
    "Similarity between sentence 1 and 3:",
    similarity[0][0]
)

5. Semantic Matching

Semantic matching compares the meaning of text rather than requiring the exact same words. 

Sentence 1:
"How can I learn Python?"

Sentence 2:
"What is the best way to study Python?"

              ↓

        Sentence Embeddings

              ↓

       Cosine Similarity

              ↓

       High similarity

Even though the words are different, the two sentences express a related meaning.

6. Example — Find the Most Similar Sentence


from sentence_transformers import SentenceTransformer
from sklearn.metrics.pairwise import cosine_similarity

model = SentenceTransformer(
    "all-MiniLM-L6-v2"
)

query = "How do I learn Python?"

sentences = [
    "What is the best way to study Python?",
    "The weather is cold today.",
    "I bought a new computer.",
    "Python programming is easy to learn."
]


query_embedding = model.encode(
    [query]
)

sentence_embeddings = model.encode(
    sentences
)


scores = cosine_similarity(
    query_embedding,
    sentence_embeddings
)[0]


best_index = scores.argmax()


print("Query:")
print(query)

print("\nMost similar sentence:")
print(sentences[best_index])

print("\nSimilarity score:")
print(scores[best_index])
