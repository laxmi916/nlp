BERT — Bidirectional Encoder Representations from Transformers

BERT is a pretrained Transformer Encoder model designed mainly for learning bidirectional contextual representations and supporting text-understanding tasks.

1. Key Idea

BERT uses bidirectional context. Each token can use information from tokens before and after it. 

The bank is near the river.
        ↑
BERT uses surrounding context
to understand "bank".

2. BERT Architecture

Input Text
    ↓
Tokenizer
    ↓
Token IDs
    ↓
Transformer Encoder
    ↓
Contextual Representations
    ↓
Task-specific Head
    ↓
Prediction

3. Pretraining

The original BERT was pretrained using Masked Language Modeling and Next Sentence Prediction. 

The cat is [MASK] on the mat.
              ↓
           sleeping

Later models such as RoBERTa showed that Next Sentence Prediction was not essential.

4. Two Important BERT Tasks

Task Purpose Model Class
Sentiment Classification Predict one class for a sentence AutoModelForSequenceClassification
Named Entity Recognition Predict an entity label for each token AutoModelForTokenClassification

5. Task 1 — Sentiment Classification

Example: 

"I really enjoyed this movie."
        ↓
BERT
        ↓
POSITIVE

Using AutoModel


pip install torch transformers


import torch
from transformers import (
    AutoTokenizer,
    AutoModelForSequenceClassification
)


# --------------------------------------------------
# 1. Model name
# --------------------------------------------------

model_name = "textattack/bert-base-uncased-SST-2"


# --------------------------------------------------
# 2. Load tokenizer
# --------------------------------------------------

tokenizer = AutoTokenizer.from_pretrained(model_name)


# --------------------------------------------------
# 3. Load pretrained model
# --------------------------------------------------

model = AutoModelForSequenceClassification.from_pretrained(
    model_name
)

# We are doing prediction, not training
model.eval()


# --------------------------------------------------
# 4. Input sentence
# --------------------------------------------------

text = "I really enjoyed this movie."

print("Input:")
print(text)


# --------------------------------------------------
# 5. Tokenize the sentence
# --------------------------------------------------

inputs = tokenizer(
    text,
    return_tensors="pt"
)

print("\nToken IDs:")
print(inputs["input_ids"])


# --------------------------------------------------
# 6. Run the model
# --------------------------------------------------

with torch.no_grad():

    outputs = model(**inputs)


# --------------------------------------------------
# 7. Convert logits to probabilities
# --------------------------------------------------

probabilities = torch.softmax(
    outputs.logits,
    dim=1
)


# --------------------------------------------------
# 8. Find the predicted class
# --------------------------------------------------

prediction = torch.argmax(
    probabilities,
    dim=1
)


# --------------------------------------------------
# 9. Convert class ID to label
# --------------------------------------------------

labels = {
    0: "NEGATIVE",
    1: "POSITIVE"
}

predicted_class = prediction.item()

predicted_label = labels[predicted_class]

confidence = probabilities[
    0, predicted_class
].item()


# --------------------------------------------------
# 10. Display result
# --------------------------------------------------

print("\nPrediction:")
print(predicted_label)

print("\nConfidence:")
print(f"{confidence:.4f}")

The model produces logits, which are converted into probabilities using softmax. This example uses a BERT checkpoint fine-tuned on SST-2.

6. Task 2 — Named Entity Recognition (NER)

NER identifies entities such as people, organizations and locations. 

Elon Musk founded SpaceX in the United States.

Elon Musk       → PERSON
SpaceX          → ORGANIZATION
United States   → LOCATION

Using AutoModel


import torch

from transformers import (
    AutoTokenizer,
    AutoModelForTokenClassification
)


# --------------------------------------------------
# 1. Model name
# --------------------------------------------------

model_name = "dslim/bert-base-NER"


# --------------------------------------------------
# 2. Load tokenizer
# --------------------------------------------------

tokenizer = AutoTokenizer.from_pretrained(
    model_name
)


# --------------------------------------------------
# 3. Load pretrained BERT NER model
# --------------------------------------------------

model = AutoModelForTokenClassification.from_pretrained(
    model_name
)

# We are doing prediction, not training
model.eval()


# --------------------------------------------------
# 4. Input sentence
# --------------------------------------------------

text = "Elon Musk founded SpaceX in California."

print("Input:")
print(text)


# --------------------------------------------------
# 5. Tokenize the sentence
# --------------------------------------------------

inputs = tokenizer(
    text,
    return_tensors="pt",
    return_special_tokens_mask=True
)

print("\nToken IDs:")
print(inputs["input_ids"])


# --------------------------------------------------
# 6. Run the BERT model
# --------------------------------------------------

with torch.no_grad():

    outputs = model(**inputs)


# --------------------------------------------------
# 7. Convert logits into probabilities
# --------------------------------------------------

probabilities = torch.softmax(
    outputs.logits,
    dim=2
)


# --------------------------------------------------
# 8. Find the predicted class for each token
# --------------------------------------------------

predictions = torch.argmax(
    probabilities,
    dim=2
)


# --------------------------------------------------
# 9. Convert token IDs into tokens
# --------------------------------------------------

tokens = tokenizer.convert_ids_to_tokens(
    inputs["input_ids"][0]
)

# Identify special tokens such as [CLS] and [SEP]
special_tokens_mask = inputs["special_tokens_mask"][0].tolist()


# --------------------------------------------------
# 10. Display token-level predictions
# --------------------------------------------------

print("\nNamed Entity Recognition:")

for i, (token, prediction) in enumerate(
    zip(tokens, predictions[0])
):

    # Skip special tokens
    if special_tokens_mask[i] == 1:
        continue

    class_id = prediction.item()
    label = model.config.id2label[class_id]

    confidence = probabilities[
        0, i, class_id
    ].item()

    print(
        f"{token:15} -> "
        f"{label:10} "
        f"({confidence:.4f})"
    )

Note: The raw token-classification output may contain subword tokens such as Space and ##X. The pipeline() example below uses aggregation_strategy="simple" to combine subwords into entity spans.

Using Pipeline


from transformers import pipeline

ner = pipeline(
    "token-classification",
    model="dslim/bert-base-NER",
    aggregation_strategy="simple"
)

text = "Elon Musk founded SpaceX."

results = ner(text)

for entity in results:
    print(
        entity["word"],
        "->",
        entity["entity_group"]
    )

RoBERTa — An Improved BERT Pretraining Approach

RoBERTa stands for Robustly Optimized BERT Pretraining Approach. It keeps the BERT-style Transformer Encoder architecture while using a stronger pretraining recipe. RoBERTa was introduced by Facebook AI (now Meta AI).

1. What is RoBERTa?

RoBERTa uses the Transformer Encoder, just like BERT, and is mainly designed for understanding text. 

BERT
  ↓
Improved pretraining strategy
  ↓
RoBERTa
  ↓
Improved pretrained representations

2. How is RoBERTa Different from BERT?

BERT RoBERTa
Uses Masked Language Modeling Uses Masked Language Modeling
Original training included NSP Removes NSP
Uses relatively smaller training setup Uses larger training data and longer training
Uses static masking in the original setup Uses dynamic masking

The key point is that RoBERTa does not introduce a fundamentally new Transformer architecture. Its main contribution is a better pretraining strategy.

3. Dynamic Masking

Instead of always masking the same words, RoBERTa can create different masking patterns during training. 

Sentence:
The cat is sitting on the mat.

Masking 1:
The [MASK] is sitting on the mat.

Masking 2:
The cat is [MASK] on the mat.

Masking 3:
The cat is sitting on the [MASK].

This exposes the model to different learning examples from the same sentence.

4. RoBERTa for Text Classification

RoBERTa can be fine-tuned for tasks such as sentiment analysis, topic classification, and other text-classification problems. 

Input Text
    ↓
RoBERTa Encoder
    ↓
Contextual Representations
    ↓
Classification Layer
    ↓
Prediction

5. Example — Sentiment Classification

Install the required libraries:

pip install torch transformers

Complete example:


import torch

from transformers import (
    AutoTokenizer,
    AutoModelForSequenceClassification
)


# Load a RoBERTa model fine-tuned for sentiment

# Load tokenizer

# Load model

    model_name
)

model.eval()


# Input sentence
text = "I really enjoyed this movie."

print("Input:")
print(text)


# Tokenization
inputs = tokenizer(
    text,
    return_tensors="pt"
)


# Prediction
with torch.no_grad():
    outputs = model(**inputs)


# Convert logits to probabilities
probabilities = torch.softmax(
    outputs.logits,
    dim=1
)


# Get predicted class
prediction = torch.argmax(
    probabilities,
    dim=1
).item()


# Get label
label = model.config.id2label[prediction]


# Get confidence

    0, prediction
].item()


print("\nPrediction:")

print("\nConfidence:")

GPT — Generative Pre-trained Transformer

GPT stands for Generative Pre-trained Transformer. GPT is a pretrained language model based on the Transformer Decoder. It is mainly designed for text generation.

1. What is GPT?

GPT generates text by predicting the next token based on the tokens that came before it. 

Input:
Artificial intelligence is

        ↓

GPT Decoder

        ↓

Next token → transforming

        ↓

Artificial intelligence is transforming...

This process is called autoregressive language modeling.

2. GPT Architecture

Input Text
    ↓
Tokenizer
    ↓
Token IDs
    ↓
Transformer Decoder
    ↓
Causal Self-Attention
    ↓
Next-Token Prediction
    ↓
Generated Text

GPT uses causal attention, which prevents a token from looking at future tokens. 

The   cat   is   sleeping

The       ✓
cat       ✓ ✓
is        ✓ ✓ ✓
sleeping  ✓ ✓ ✓ ✓

Therefore, when predicting the next token, GPT can only use the tokens that have already appeared.

3. GPT Training

GPT is trained to predict the next token. 

The cat
   ↓
predict: is

The cat is
   ↓
predict: sleeping

The cat is sleeping
   ↓
predict: ...

The objective can be represented as: 

P(xₜ | x₁, x₂, ..., xₜ₋₁)

4. GPT vs BERT

BERT GPT
Transformer Encoder Transformer Decoder
Bidirectional context Left-to-right context
Mainly understands text Mainly generates text
Masked Language Modeling Next-token prediction

5. Example — Text Generation

Install the required libraries:

pip install torch transformers

The following example uses GPT-2, a small and widely used GPT-family model. 


import torch

from transformers import (
    AutoTokenizer,
    AutoModelForCausalLM
)


# --------------------------------------------------
# 1. Load pretrained GPT model
# --------------------------------------------------

model_name = "openai-community/gpt2"


tokenizer = AutoTokenizer.from_pretrained(
    model_name
)


model = AutoModelForCausalLM.from_pretrained(
    model_name
)

model.eval()


# --------------------------------------------------
# 2. Input prompt
# --------------------------------------------------

text = "Artificial intelligence is"

print("Prompt:")
print(text)


# --------------------------------------------------
# 3. Tokenize
# --------------------------------------------------

inputs = tokenizer(
    text,
    return_tensors="pt"
)


print("\nInput token IDs:")
print(inputs["input_ids"])


# --------------------------------------------------
# 4. Generate text
# --------------------------------------------------

with torch.no_grad():

    output_ids = model.generate(
        **inputs,
        max_new_tokens=30,
        do_sample=True,
        temperature=0.7
    )


# --------------------------------------------------
# 5. Convert token IDs to text
# --------------------------------------------------

generated_text = tokenizer.decode(
    output_ids[0],
    skip_special_tokens=True
)


# --------------------------------------------------
# 6. Display result
# --------------------------------------------------

print("\nGenerated Text:")
print(generated_text)

         Tokenizer
             ↓
          Token IDs
             ↓
         GPT-2 Model
             ↓
       Predict next token
             ↓
       Predict next token
             ↓
             ...
             ↓
       Generated sentence

LLaMA — Large Language Model Meta AI

LLaMA is a family of pretrained decoder-only Transformer language models developed by Meta. Like GPT, LLaMA uses causal self-attention and predicts the next token to generate text.

1. Key Idea

Prompt
  ↓
LLaMA Decoder
  ↓
Predict Next Token
  ↓
Predict Next Token
  ↓
...
  ↓
Generated Text

LLaMA is therefore primarily designed for text generation and language-modeling tasks.

2. LLaMA Architecture

Input Text
    ↓
Tokenizer
    ↓
Token IDs
    ↓
LLaMA Transformer Decoder
    ↓
Causal Self-Attention
    ↓
Next-Token Prediction
    ↓
Generated Text

Like GPT, each token can attend only to the tokens that occur before it. This allows LLaMA to generate text autoregressively.

3. LLaMA vs BERT, GPT and T5

Model Architecture Main Use
BERT Encoder Analyze / represent text
GPT Decoder Generate text
T5 Encoder-Decoder Transform text to text
LLaMA Decoder Generate and understand text through autoregressive modeling

4. When to Use LLaMA?

LLaMA is particularly natural when the task requires a decoder-only language model to generate or process text autoregressively.

  • Text Generation
  • Chat Applications
  • Question Answering
  • Code Generation
  • Instruction Following
  • Summarization
  • Conversational Systems
  • Generative RAG

Use LLaMA-family models when your application needs a generative language model that can produce new text from a prompt.

Ollama — Running LLMs Locally

Ollama is a tool for running large language models locally on a computer. It provides a simple way to download, manage, and interact with models such as LLaMA and other supported models.

1. LLaMA vs Ollama

LLaMA Ollama
Language model family LLM runtime / tool
Developed by Meta Used to run models locally
Defines the model Runs and manages the model
Example: LLaMA 3 Example: ollama run llama3

3. Install and Run a Model

After installing Ollama, open a terminal and run: 

ollama pull llama3.2

Then start an interactive conversation: 

ollama run llama3.2

You can now enter a prompt such as: 

Explain artificial intelligence in simple words.

  • Run supported LLMs locally

Ollama is not limited to Meta's LLaMA models. It supports models from many organizations, as long as the model is available in a format and architecture supported by Ollama.

Examples of supported model families include:

  • LLaMA — Meta
  • Qwen — Alibaba
  • Gemma — Google
  • Mistral — Mistral AI
  • Phi — Microsoft

  • gpt-oss — OpenAI's open-weight models

Therefore, Ollama is a runtime/tool for running supported models locally, not a model itself.

Ollama primarily targets models that fit its supported local inference ecosystem, especially generative LLMs. BERT and T5 are different architectural families and are generally used through frameworks such as Hugging Face Transformers rather than being typical Ollama choices.

T5 — Text-to-Text Transfer Transformer

T5 stands for Text-to-Text Transfer Transformer. It is a pretrained Encoder-Decoder Transformer designed to solve NLP tasks by converting one text sequence into another.

1. Key Idea

T5 treats many NLP tasks as text-to-text problems.

Input Text
    ↓
T5 Encoder
    ↓
T5 Decoder
    ↓
Output Text

translate English to French: Hello
              ↓
           Bonjour

2. T5 Architecture

Input
  ↓
Tokenizer
  ↓
Transformer Encoder
  ↓
Encoded Representation
  ↓
Transformer Decoder
  ↓
Generated Output

The encoder processes the input sequence, while the decoder generates the output sequence.

3. Why is T5 Different?

TaskInputOutput
Translationtranslate English to French: HelloBonjour
Summarizationsummarize: Long article...Short summary
Question Answeringquestion + contextAnswer
Text Transformationrewrite: Original sentenceRewritten sentence

4. T5 vs BERT vs GPT

ModelArchitectureMain Use
BERTEncoderAnalyze / represent text
GPTDecoderGenerate text
T5Encoder-DecoderTransform one text into another

5. When to Use T5?

T5 is particularly natural when the task has the form:

Input Text
    ↓
Understand Input
    ↓
Generate Another Text
  • Machine Translation
  • Text Summarization
  • Question Answering
  • Text Rewriting
  • Grammar Correction
  • Text-to-Text Classification

Use an encoder-decoder model such as T5 when you need to transform one sequence of text into another.

6. Example — English to French Translation

Install the required libraries:

pip install torch transformers sentencepiece
import torch
from transformers import AutoTokenizer, AutoModelForSeq2SeqLM

model_name = "t5-small"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForSeq2SeqLM.from_pretrained(model_name)
model.eval()

text = "translate English to French: I am learning artificial intelligence."

inputs = tokenizer(text, return_tensors="pt")

with torch.no_grad():
    output_ids = model.generate(
        **inputs,
        max_new_tokens=30
    )

translation = tokenizer.decode(
    output_ids[0],
    skip_special_tokens=True
)

print("Input:")
print(text)
print("\nOutput:")
print(translation)
