Semantic Search and Dense Retrieval

Semantic search retrieves documents based on their meaning rather than only matching exact keywords. In dense retrieval, both the query and documents are converted into dense embedding vectors and compared using a similarity measure such as cosine similarity.

1. Embedding-Based Retrieval

Documents
    ↓
Embedding Model
    ↓
Document Embeddings
    ↓
Store Embeddings

User Query
    ↓
Embedding Model
    ↓
Query Embedding
    ↓
Similarity Search
    ↓
Relevant Documents

2. Query → Embedding → Similarity → Documents

Query:
"How can I learn Python?"

        ↓

Query Embedding

        ↓

Compare with document embeddings

        ↓

        ↓

        ↓

Most relevant documents

3. Example — Simple Dense Retrieval

Install the required libraries:

pip install sentence-transformers scikit-learn


from sentence_transformers import SentenceTransformer
from sklearn.metrics.pairwise import cosine_similarity


# --------------------------------------------------
# 1. Load embedding model
# --------------------------------------------------

model = SentenceTransformer(
    "all-MiniLM-L6-v2"
)


# --------------------------------------------------
# 2. Documents
# --------------------------------------------------

documents = [
    "Python is a popular programming language.",
    "Deep learning uses neural networks to learn patterns.",
    "Transformers are widely used in natural language processing.",
    "Machine learning allows computers to learn from data.",
    "Football is a popular sport."
]


# --------------------------------------------------
# 3. Convert documents into embeddings
# --------------------------------------------------

document_embeddings = model.encode(
    documents
)


# --------------------------------------------------
# 4. User query
# --------------------------------------------------

query = "How can I learn Python programming?"


# --------------------------------------------------
# 5. Convert query into an embedding
# --------------------------------------------------

query_embedding = model.encode(
    [query]
)


# --------------------------------------------------
# 6. Calculate similarity
# --------------------------------------------------

scores = cosine_similarity(
    query_embedding,
    document_embeddings
)[0]


# --------------------------------------------------
# 7. Rank documents
# --------------------------------------------------

ranked_indices = scores.argsort()[::-1]


# --------------------------------------------------
# 8. Display results
# --------------------------------------------------

print("Query:")
print(query)

print("\nRetrieved Documents:")

for index in ranked_indices:

    print(
        "\nScore:",
        scores[index]
    )

    print(
        "Document:",
        documents[index]
    )

5. Top-K Retrieval

In a real search system, we normally retrieve only the top-K most similar documents. 


top_k = 3

for index in ranked_indices[:top_k]:

    print(
        scores[index],
        "->",
        documents[index]
    )

6. Keyword Search vs Semantic Search

Keyword Search Semantic Search
Matches words Compares meaning
Exact terms can be important Similar wording can still match
Often uses inverted indexes Uses dense embeddings
Example: TF-IDF / BM25 Example: Transformer embeddings

7. Dense Retrieval

Dense retrieval represents each document and query as a dense vector and retrieves documents whose vectors are most similar to the query vector. 

Query
  ↓
Dense Query Vector
  ↓
Vector Similarity Search
  ↓
Top-K Dense Vectors
  ↓
Relevant Documents

8. Applications

  • Semantic search
  • Question answering
  • Document retrieval
  • Knowledge-base search
  • Recommendation systems
  • Retrieval-Augmented Generation (RAG)

9. Key Takeaway

Query
  ↓
Embedding
  ↓
Similarity Search
  ↓
Rank Documents
  ↓
Top-K Relevant Documents

Semantic search converts the search problem from matching words to matching vector representations of meaning.
