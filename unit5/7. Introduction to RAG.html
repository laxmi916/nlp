Introduction to RAG

Retrieval-Augmented Generation (RAG) combines information retrieval with a language model. Instead of asking an LLM to answer only from its internal knowledge, RAG first retrieves relevant information and then provides that information to the LLM as context. 

User Question
      ↓
   Retrieval
      ↓
Relevant Documents
      ↓
Context Augmentation
      ↓
LLM / Generator
      ↓
Final Answer

1. Why RAG?

A pretrained LLM may not know information from a private document, internal knowledge base, or recently added data. RAG allows the model to retrieve relevant external information at query time. 

Without RAG:

Question → LLM → Answer


With RAG:

Question
   ↓
Retrieve relevant information
   ↓
Question + Retrieved Context
   ↓
LLM
   ↓
Answer

2. The Three Main Steps

Step 1 — Retrieval

The system searches a collection of documents and retrieves the pieces that are most relevant to the user's question. 

Question
   ↓
Query Embedding
   ↓
Similarity Search
   ↓
Top-K Documents

Step 2 — Context Augmentation

The retrieved information is added to the user's question to create an augmented prompt. 

Question
   +
Retrieved Documents
   ↓
Augmented Prompt

Step 3 — Generation

The language model receives the augmented prompt and generates the final answer using the retrieved context. 

Augmented Prompt
       ↓
      LLM
       ↓
Generated Answer

3. Complete RAG Pipeline

                 Documents
                     ↓
                  Chunking
                     ↓
              Embedding Model
                     ↓
              Vector Database
                     │
                     │
User Query ──→ Embedding Model
                     ↓
               Similarity Search
                     ↓
              Relevant Chunks
                     ↓
          Context + User Question
                     ↓
                  LLM
                     ↓
                  Answer

4. Example — Simple RAG Without a Vector Database

First, we can understand the RAG concept using a small collection of documents and cosine similarity.

Install the required libraries:

pip install sentence-transformers scikit-learn


from sentence_transformers import SentenceTransformer
from sklearn.metrics.pairwise import cosine_similarity


# --------------------------------------------------
# 1. Knowledge base
# --------------------------------------------------

documents = [

    "Python is a programming language used for web development, "
    "data science, automation, and artificial intelligence.",

    "Machine learning is a branch of artificial intelligence "
    "that learns patterns from data.",

    "Deep learning uses neural networks with multiple layers "
    "to learn complex patterns.",

    "Transformers are neural network architectures widely used "
    "for natural language processing.",

    "RAG combines information retrieval with language generation."
]


# --------------------------------------------------
# 2. Load embedding model
# --------------------------------------------------

embedding_model = SentenceTransformer(
    "all-MiniLM-L6-v2"
)


# --------------------------------------------------
# 3. Create document embeddings
# --------------------------------------------------

document_embeddings = embedding_model.encode(
    documents
)


# --------------------------------------------------
# 4. User question
# --------------------------------------------------

question = "What is RAG?"


# --------------------------------------------------
# 5. Convert question into an embedding
# --------------------------------------------------

question_embedding = embedding_model.encode(
    [question]
)


# --------------------------------------------------
# 6. Calculate similarity
# --------------------------------------------------

scores = cosine_similarity(
    question_embedding,
    document_embeddings
)[0]


# --------------------------------------------------
# 7. Retrieve top documents
# --------------------------------------------------

top_k = 2

top_indices = scores.argsort()[
    ::-1
][:top_k]


# --------------------------------------------------
# 8. Display retrieved context
# --------------------------------------------------

print("Question:")
print(question)

print("\nRetrieved Context:")

for index in top_indices:

    print(
        "\nScore:",
        scores[index]
    )

    print(
        "Document:",
        documents[index]
    )

5. What Happened?

Question:
"What is RAG?"

        ↓

Question Embedding

        ↓

Compare with document embeddings

        ↓

Cosine Similarity

        ↓

Rank documents

        ↓

Retrieve top 2 documents

At this point we have completed the retrieval part of RAG. The next step is to give the retrieved information to a generative model.

6. Context Augmentation

We combine the retrieved documents with the user's question. 


context = "\n".join(
    documents[index]
    for index in top_indices
)


prompt = f"""
Use the following context to answer the question.

Context:
{context}

Question:
{question}

Answer:
"""

print(prompt)

The resulting prompt provides the language model with external context.

7. Example — Complete RAG with a Local T5 Generator

The following example performs retrieval and then sends the retrieved context to a pretrained T5 model for generation.

Install:

pip install torch transformers sentence-transformers scikit-learn


import torch

from sentence_transformers import SentenceTransformer

from sklearn.metrics.pairwise import cosine_similarity

from transformers import (
    AutoTokenizer,
    AutoModelForSeq2SeqLM
)


# ==================================================
# 1. Knowledge base
# ==================================================

documents = [

    "Python is a programming language used for "
    "data science and artificial intelligence.",

    "Machine learning enables computers to learn "
    "patterns from data.",

    "Deep learning uses multi-layer neural networks "
    "to learn complex patterns.",

    "RAG combines retrieval of external information "
    "with language model generation."

]


# ==================================================
# 2. Embedding model
# ==================================================

embedding_model = SentenceTransformer(
    "all-MiniLM-L6-v2"
)


# ==================================================
# 3. Create document embeddings
# ==================================================

document_embeddings = embedding_model.encode(
    documents
)


# ==================================================
# 4. User question
# ==================================================

question = "What is RAG?"


# ==================================================
# 5. Query embedding
# ==================================================

query_embedding = embedding_model.encode(
    [question]
)


# ==================================================
# 6. Similarity search
# ==================================================

scores = cosine_similarity(
    query_embedding,
    document_embeddings
)[0]


# ==================================================
# 7. Retrieve top documents
# ==================================================

top_k = 2

top_indices = scores.argsort()[
    ::-1
][:top_k]


# ==================================================
# 8. Build context
# ==================================================

context = "\n".join(
    documents[index]
    for index in top_indices
)


# ==================================================
# 9. Create augmented prompt
# ==================================================

prompt = f"""
Answer the question using the context.

Context:
{context}

Question:
{question}

Answer:
"""


# ==================================================
# 10. Load T5
# ==================================================

model_name = "google/flan-t5-small"

tokenizer = AutoTokenizer.from_pretrained(
    model_name
)

model = AutoModelForSeq2SeqLM.from_pretrained(
    model_name
)


# ==================================================
# 11. Tokenize augmented prompt
# ==================================================

inputs = tokenizer(
    prompt,
    return_tensors="pt",
    truncation=True
)


# ==================================================
# 12. Generate answer
# ==================================================

with torch.no_grad():

    output_ids = model.generate(
        **inputs,
        max_new_tokens=50
    )


# ==================================================
# 13. Decode answer
# ==================================================

answer = tokenizer.decode(
    output_ids[0],
    skip_special_tokens=True
)


# ==================================================
# 14. Display result
# ==================================================

print("Question:")
print(question)

print("\nRetrieved Context:")
print(context)

print("\nGenerated Answer:")
print(answer)

8. Understanding the Complete Program

documents
    ↓
all-MiniLM-L6-v2
    ↓
Document Embeddings
    │
    │
    │       User Question
    │              ↓
    │       Query Embedding
    │              ↓
    └──── Similarity Search
                   ↓
             Top-K Documents
                   ↓
                Context
                   ↓
          Question + Context
                   ↓
             FLAN-T5
                   ↓
               Answer

9. RAG vs Normal LLM

Normal LLM RAG
Question → LLM → Answer Question → Retrieval → Context → LLM → Answer
Relies mainly on learned parameters Uses external retrieved information
Knowledge is difficult to update without additional training Knowledge can be updated by changing the knowledge source
No retrieval step Explicit retrieval step

10. RAG with a Vector Database

The simple example above calculates similarity directly. Real RAG systems usually store embeddings in a vector database or vector index. 

Documents
    ↓
Chunking
    ↓
Embedding
    ↓
Vector Database
    ↓
        Query
          ↓
       Embedding
          ↓
    Vector Search
          ↓
       Top-K Chunks
          ↓
       LLM Context
          ↓
        Answer

Examples of technologies commonly used for vector retrieval include FAISS, Chroma, Qdrant, Milvus, and other vector databases.

11. Important RAG Components

Component Purpose
Documents Source knowledge used by the system.
Chunking Breaks large documents into smaller pieces.
Embedding Model Converts text into dense vectors.
Vector Store Stores and searches document embeddings.
Retriever Finds relevant document chunks.
Context Retrieved information supplied to the LLM.
Generator Produces the final natural-language answer.

12. Key Takeaway

             RAG

Retrieval
    ↓
Find relevant information

Context Augmentation
    ↓
Add retrieved information to the prompt

Generation
    ↓
LLM generates the answer

RAG = Retrieval + Context Augmentation + Generation.

The central idea is simple: retrieve relevant knowledge first, give that knowledge to the language model as context, and then generate the answer.
