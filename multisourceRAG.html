Building a Multi-Source RAG Pipeline with LangChain and Gemini

Here is a comprehensive tutorial on building a robust RAG (Retrieval-Augmented Generation) pipeline that ingests a local PDF file, processes web data from an external URL, and utilizes LangChain integrated with official Gemini API models.

1. Install Dependencies

We need packages to extract text from PDFs, pull web pages, manage the LangChain orchestration framework, and house an in-memory vector database (Chroma).

pip install langchain langchain-community langchain-google-genai pypdf chromadb

2. Set Up Environment & Authentication

LangChain seamlessly connects with Google's native API wrapper langchain-google-genai. Secure your credentials by saving your API key to your environment variables.

import os

# Set your Gemini API key securely
os.environ["GOOGLE_API_KEY"] = "YOUR_GEMINI_API_KEY"

3. Load Documents from Multiple Sources (PDF & Web)

We use LangChain's data loaders to ingest information from distinct text sources.

from langchain_community.document_loaders import PyPDFLoader, WebBaseLoader

# Source 1: Extract data from a local PDF file
pdf_loader = PyPDFLoader("sample_document.pdf")
pdf_docs = pdf_loader.load()

# Source 2: Extract data from an external webpage/documentation URL
web_loader = WebBaseLoader("https://ai.google.dev/gemini-api/docs")
web_docs = web_loader.load()

# Combine both documentation streams into a single list
all_documents = pdf_docs + web_docs
print(f"Loaded {len(all_documents)} raw pages/documents from both sources.")

4. Chunk and Split the Document Content

Language models struggle with massive chunks of raw text. Splitting the documents into digestible semantic pieces maintains retrieval accuracy.

from langchain_text_splitters import RecursiveCharacterTextSplitter

# Initialize text splitter tool
text_splitter = RecursiveCharacterTextSplitter(
    chunk_size=1000, 
    chunk_overlap=200
)

# Segment our parsed pages into standardized chunks
doc_chunks = text_splitter.split_documents(all_documents)
print(f"Segmented sources into {len(doc_chunks)} distinct text blocks.")

5. Index Document Blocks in a Vector Store via Gemini Embeddings

We pass our document blocks to the Gemini Embedding model and record those mathematical vectors inside ChromaDB.

from langchain_community.vectorstores import Chroma
from langchain_google_genai import GoogleGenerativeAIEmbeddings

# Initialize the official Gemini Embeddings Model
embeddings = GoogleGenerativeAIEmbeddings(model="models/text-embedding-004")

# Embed and store chunks inside an in-memory database
vector_store = Chroma.from_documents(
    documents=doc_chunks, 
    embedding=embeddings
)

# Convert the database into a specialized LangChain Retriever
retriever = vector_store.as_retriever(search_kwargs={"k": 3})
print("Knowledge base successfully indexed inside the Vector DB.")

6. Construct the RAG Chain Architecture

from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnablePassthrough
from langchain_google_genai import ChatGoogleGenerativeAI

# 1. Initialize the official Gemini generation engine via LangChain
llm = ChatGoogleGenerativeAI(
    model="gemini-2.5-flash",
    temperature=0,
)

# 2. Design a foundational system prompt to ground the assistant
rag_prompt_template = """
You are a factual, context-aware AI assistant. Answer the question using strictly only the provided background context.
If the answer cannot be confidently formulated from the context, explicitly say: "I do not have sufficient data from the source files to answer."

Context:
{context}

Question: 
{question}

Answer:
"""

prompt = ChatPromptTemplate.from_template(rag_prompt_template)

# 3. Helper utility to clean up and join retrieved context snippets
def format_docs(docs):
    return "\n\n".join(doc.page_content for doc in docs)

# 4. Construct the definitive RAG Chain assembly
rag_chain = (
    {"context": retriever | format_docs, "question": RunnablePassthrough()}
    | prompt
    | llm
    | StrOutputParser()
)

7. Run a Query through the Pipeline

user_query = "What specific features or metrics are detailed in the document?"

# Invoke the execution pipeline
response = rag_chain.invoke(user_query)

print("\n--- LangChain + Gemini RAG Output ---")
print(response)

Quick Architecture Reference

  • Ingestion layer (PyPDFLoader / WebBaseLoader): Safely pulls text data from flat file layers or live web addresses.
  • Vector layer (GoogleGenerativeAIEmbeddings): Computes context similarity across standard textual blocks.
  • Generation layer (ChatGoogleGenerativeAI): Leverages gemini-2.5-flash to process structural prompt blocks and output fluent, accurate responses.
