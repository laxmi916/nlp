Tutorial: Understanding and Building Agentic AI

Unlike a standard Retrieval-Augmented Generation (RAG) pipeline—which follows a strict, predictable path of searching data and answering a question— Agentic AI represents a shift toward autonomy.

Instead of executing a fixed code script, an Agentic system acts as an independent entity. You provide it with a goal and a suite of "tools" (Python functions, web scrapers, or calculators), and the model dynamically decides which tool to use, when to use it, and how to evaluate if the results are sufficient to solve your request.

Key Structural Differences: RAG vs. Agents

Feature RAG (Retrieval-Augmented) Agentic AI
Control Flow Deterministic (Fixed steps) Adaptive (Dynamic loops)
Reasoning Single-turn context synthesis Multi-turn planning, execution, and evaluation
Action Capability Read-only (Fetches text data) Read/Write (Executes calculations, triggers APIs)
Success Metric Semantic search matching accuracy Task goal achievement and problem-solving

Building a Currency Conversion Agent with Gemini

We will build an AI financial agent. When a user asks a complex question like: "How much is a $450 jacket in Euros if there is a 12% sales tax?", a basic LLM might hallucinate the math or use outdated conversion rates.

Our Agent will use Gemini's Native Function Calling to dynamically call a real local mathematical calculation tool and coordinate the correct solution.

1. Install Dependencies

First, make sure you have the official, modern Google GenAI SDK installed:

pip install google-genai

2. Define the Agent's Tools

Tools are standard Python functions. By including clear docstrings and type hints, the Gemini model reads this metadata to understand exactly what the function does and what arguments it requires.

def calculate_total_with_tax(price: float, tax_rate: float) -> float: """ Calculates the final total cost of an item after applying sales tax. Args: price: The initial base cost of the item before tax. tax_rate: The tax percentage expressed as a decimal (e.g., 0.12 for 12%). """ return price * (1 + tax_rate) def convert_usd_to_eur(usd_amount: float) -> float: """ Converts a USD currency value into EUR currency values. Args: usd_amount: The numerical amount in US Dollars. """ # Using a fixed baseline exchange rate for this local tool context exchange_rate = 0.92 return usd_amount * exchange_rate

3. Initialize the Client and Bind Tools

import os from google import genai from google.genai import types # Initialize client using your Gemini API key environment variable api_key = os.environ.get("GEMINI_API_KEY", "YOUR_GEMINI_API_KEY") client = genai.Client(api_key=api_key) # Package tools so the Gemini API can recognize their schema signature my_agent_tools = [calculate_total_with_tax, convert_usd_to_eur]

4. Run the Agentic Execution Loop

The modern google-genai SDK supports automated function/tool execution.

# User command requiring multiple distinct calculation phases user_prompt = "I want to buy a jacket that costs $450 USD. The local store has a 12% sales tax. How much will it cost me total in Euros?" print(f"User Request: {user_prompt}\n") print("--- Agent Execution Trace ---") # Execute content generation with function routing turned on response = client.models.generate_content( model="gemini-2.5-flash", contents=user_prompt, config=types.GenerateContentConfig( tools=my_agent_tools, temperature=0.0 # Low temperature guarantees strict logical reasoning ) ) print("\n--- Final Agent Response ---") print(response.text)

How the Agent Solved It Behind the Scenes

  1. Analysis: The model reads the prompt and determines it cannot solve the math directly using language alone.
  2. Step 1 (Tax Calculation): Executes calculate_total_with_tax(price=450, tax_rate=0.12) returning $504.0.
  3. Step 2 (Currency Conversion): Executes convert_usd_to_eur(usd_amount=504.0).
  4. Synthesis: Converts results into readable assistant output.

Best Practices for Production Agents

  • Granular Tools: Each tool should perform one task well.
  • Error Handling: Use try/except so errors can be surfaced back to the LLM.
  • Traceability: Log tool calls and agent decisions for debugging.
  • Security: Validate inputs before tool execution.
