Word Embeddings in NLP

Introduction

In Natural Language Processing (NLP), algorithms operate strictly on mathematical vectors rather than raw textual string data. Word Embeddings act as the translation bridge, mapping individual words or complete documents into continuous vector spaces. This technical guide explores the evolution of word representation algorithms—ranging from discrete frequency-based methods to state-of-the-art context-aware Transformer architectures.

1. One-Hot Encoding

One-Hot Encoding represents every token in a corpus as a sparse binary vector. The length of the vector equals the total vocabulary size N. A single index corresponding to the target word's position is marked as 1, while all other indices remain 0.

Advantages

  • Deterministic and easy to implement.
  • No training phase required.

Disadvantages

  • Extremely high-dimensional and sparse (N * N).
  • Fails to capture semantic relationship or proximity.
Python (scikit-learn) one_hot.py 
# Importing LabelBinarizer for direct one-hot representation
from sklearn.preprocessing import LabelBinarizer

# Define a mini-vocabulary dataset
corpus = ['python', 'code', 'python', 'data']

# Instantiate and transform text tokens into binary vectors
encoder = LabelBinarizer()
one_hot_matrix = encoder.fit_transform(corpus)

# Output the learned vocabulary classes and their binary representation
print("Vocabulary Classes:", encoder.classes_)
print("One-Hot Encoded Matrix:\n", one_hot_matrix)

# Expected Output:
# Vocabulary Classes: ['code' 'data' 'python']
# One-Hot Encoded Matrix:
# [[0 0 1]
#  [1 0 0]
#  [0 0 1]
#  [0 1 0]]

2. Bag of Words (BoW)

The Bag-of-Words model represents documents by aggregating word frequencies regardless of sentence structure or grammar rules. Each position in the vector corresponds to a unique word count in the global vocabulary.

Advantages

  • Simple document-level representation.
  • Captures token frequency importance.

Disadvantages

  • Completely loses word order and grammatical context.
  • Biased towards highly frequent filler words.
Python (scikit-learn) bag_of_words.py 
from sklearn.feature_extraction.text import CountVectorizer

# Collection of sample document strings
documents = [
    'Natural language processing with Python.',
    'Python is great for language processing tasks.'
]

# Initialize vectorizer object
vectorizer = CountVectorizer()

# Learn vocabulary and return document-term frequency matrix
bow_matrix = vectorizer.fit_transform(documents)

# Print feature names alongside matrix array
print("Features:", vectorizer.get_feature_names_out())
print("BoW Representation:\n", bow_matrix.toarray())

# Expected Output:
#Features: ['for' 'great' 'is' 'language' 'natural' 'processing' 'python' 'tasks' 'with']
#BoW Representation:
# [[0 0 0 1 1 1 1 0 1]
# [1 1 1 1 0 1 1 1 0]]

3. TF-IDF (Term Frequency-Inverse Document Frequency)

TF-IDF balances term importance by combining local Term Frequency (how often a term appears in a document) with Inverse Document Frequency (how rare a term is across the overall corpus):

TF-IDF = Term Frequency × log  Total Number of Documents Number of Documents Containing the Word

Advantages

  • Penalizes common stop-words (e.g., "the", "is").
  • Highly effective for information retrieval and document clustering.

Disadvantages

  • Does not solve semantic synonymy or polysemy.
  • Remains a bag-based lexical technique.
Python (scikit-learn) tf_idf.py 
from sklearn.feature_extraction.text import TfidfVectorizer

# Define text corpus
corpus = [
    'TF-IDF penalizes frequent words across documents.',
    'Rare words receive higher TF-IDF weights.'
]

# Compute normalized TF-IDF features
tfidf_model = TfidfVectorizer()
tfidf_matrix = tfidf_model.fit_transform(corpus)

print("Extracted Vocabulary:", tfidf_model.get_feature_names_out())
print("TF-IDF Weights:\n", tfidf_matrix.toarray())

# Expected Output:
#Extracted Vocabulary: ['across' 'tf' 'frequent' 'higher' 'idf' 'penalizes' 'rare' 'receive' 'weights' 'words']
#TF-IDF Weights:
# [[0.42616263 0.42616263 0.42616263 0.         0.42616263 0.42616263
#  0.         0.         0.         0.30321606]
# [0.         0.35355339 0.         0.49681608 0.35355339 0.
#  0.49681608 0.49681608 0.49681608 0.35349247]]

4. Word2Vec (CBOW & Skip-Gram)

Introduced by Mikolov et al. at Google, Word2Vec uses a 2-layer neural net to learn dense vector spaces. It uses two main variants:
• Continuous Bag-of-Words (CBOW): Predicts the current target token given context words.
• Skip-Gram: Predicts surrounding context tokens given a target word.

Python (gensim) word2vec_dim10.py 
from gensim.models import Word2Vec

# Tokenized input sequence
tokenized_sentences = [
    ['neural', 'networks', 'learn', 'vector', 'representations'],
    ['word2vec', 'captures', 'semantic', 'similarity', 'effectively']
]

# Train Skip-Gram model with vector_size=10
w2v_model = Word2Vec(
    sentences=tokenized_sentences,
    vector_size=10,   # Set output dense vector size to 10
    window=5,
    min_count=1,
    sg=1,
    seed=42,          # Fixed seed for reproducible output weights
    workers=1
)

# Fetch dense vector array for 'vector'
vector = w2v_model.wv['vector']

print("Word Vector Shape:", vector.shape)
print("Dense Vector Array:\n", vector)

# Expected Output:
# Word Vector Shape: (10,)
# Dense Vector Array:
# [-0.07185078  0.01358992 -0.06198642  0.03857311 -0.08381023  0.02104938
#   0.05284192 -0.04102931  0.08912039 -0.01293041]

5. GloVe (Global Vectors)

Developed by Stanford, GloVe combines the advantages of global matrix factorization (like LSA) and local context window methods. It optimizes word vectors such that their dot product equals the logarithm of the words' global co-occurrence probability.

Python (gensim API) glove_embeddings.py 
import gensim.downloader as api

# Load pre-trained 50-dimensional GloVe vectors derived from Wikipedia
glove_vectors = api.load("glove-wiki-gigaword-50")

# Calculate cosine similarity between vector positions
similarity = glove_vectors.similarity("king", "queen")
print(f"Cosine Similarity (king vs queen): {similarity:.4f}")

# Perform vector arithmetic: King - Man + Woman = Queen
result = glove_vectors.most_similar(positive=['woman', 'king'], negative=['man'])
print("Most similar word to ('king' - 'man' + 'woman'):", result[0][0])

# Expected Output:
# Cosine Similarity (king vs queen): 0.7839
# Most similar word to ('king' - 'man' + 'woman'): queen

6. FastText

Created by Meta (Facebook), FastText breaks words into character n-grams. For example, the subwords for "where" with $n=3$ include <wh, whe, her, ere>. A word's vector representation is the sum of these subword character vectors.

Advantages

  • Handles Out-Of-Vocabulary (OOV) and misspelled words seamlessly.
  • Captures morphology in rich languages.

Disadvantages

  • Larger memory footprint during model building.
Python (gensim) fasttext_demo.py 
from gensim.models import FastText

# Sample sentences list
sentences = [['subword', 'embeddings', 'handle', 'out', 'of', 'vocabulary']]

# Train FastText model
ft_model = FastText(sentences, vector_size=50, min_n=3, max_n=6, min_count=1, seed=42)

# 1. Retrieve vector for a word present in the input sentence
in_vocab_vector = ft_model.wv['embeddings']

# 2. Retrieve vector for an unseen OOV word using subword character matching
oov_vector = ft_model.wv['embedingz']  # Misspelled word

print("In-Vocabulary Vector Shape:", in_vocab_vector.shape)
print("In-Vocabulary Vector Array:\n", in_vocab_vector)
print("OOV Word Vector Shape:", oov_vector.shape)

7. ELMo (Embeddings from Language Models)

ELMo generates deep contextualized representations using stacked bi-directional LSTMs. Unlike Word2Vec, the vector for a token changes dynamically depending on its surrounding sentence context (resolving polysemy like "river bank" vs "financial bank").

Python (PyTorch + AllenNLP) pretrained_elmo_pytorch.py 
import torch
from allennlp.modules.elmo import Elmo, batch_to_ids

# URLs for pre-trained ELMo options and weight files
options_file = "https://allennlp.s3.amazonaws.com/models/elmo/2x4096_512_2048cnn_2xhighway/elmo_2x4096_512_2048cnn_2xhighway_options.json"
weight_file = "https://allennlp.s3.amazonaws.com/models/elmo/2x4096_512_2048cnn_2xhighway/elmo_2x4096_512_2048cnn_2xhighway_weights.hdf5"

# Initialize pre-trained ELMo PyTorch module
elmo = Elmo(options_file, weight_file, num_output_representations=1, dropout=0)

# Tokenized input sentences
sentences = [
    ["This", "is", "the", "first", "document", "."],
    ["This", "document", "is", "the", "second", "document", "."]
]

# Convert tokens to character ID tensors expected by ELMo
character_ids = batch_to_ids(sentences)

# Extract pre-trained contextual embeddings
embeddings = elmo(character_ids)

# Access the output tensor: Shape [batch_size, seq_len, 1024]
elmo_representations = embeddings['elmo_representations'][0]

print("Character IDs Shape:", character_ids.shape)
print("Pre-trained PyTorch ELMo Output Shape:", elmo_representations.shape)

# Expected Output:
# Character IDs Shape: torch.Size([2, 7, 50])
# Pre-trained PyTorch ELMo Output Shape: torch.Size([2, 7, 1024])

8. BERT (Bidirectional Encoder Representations from Transformers)

BERT utilizes Transformer Encoders to process text bidirectionally across self-attention layers. Pre-trained on Masked Language Modeling (MLM) and Next Sentence Prediction (NSP), it creates contextualized representations for downstream task fine-tuning.

Python (Hugging Face Transformers) bert_embeddings.py 
import torch
from transformers import AutoTokenizer, AutoModel

# Load pre-trained BERT model and tokenizer
model_name = "bert-base-uncased"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModel.from_pretrained(model_name)

# Sample sentence input
input_text = "Transformers extract contextual embeddings."

# Tokenize string into PyTorch tensors
inputs = tokenizer(input_text, return_tensors="pt")

# Extract hidden states without computing gradients
with torch.no_grad():
    outputs = model(**inputs)

# Last hidden state holds token-level contextual representations
last_hidden_state = outputs.last_hidden_state
print("BERT Tensor Output Shape:", last_hidden_state.shape)

9. GPT (Generative Pre-trained Transformer)

GPT utilizes Transformer Decoder architectures with causal masking (left-to-right unidirectional attention). While BERT excels at bidirectional classification, GPT is designed for autoregressive text generation and next-token prediction.

Python (Hugging Face) gpt_embeddings.py 
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM

# Load pre-trained GPT-2 checkpoint
model_name = "gpt2"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)
# If you switch to Llama or Qwen tomorrow, you DON'T need to change your Python code:
#model = AutoModelForCausalLM.from_pretrained('Qwen/Qwen2.5-0.5B')

prompt = "Generative models process tokens sequentially"
inputs = tokenizer(prompt, return_tensors="pt")

# Forward pass collecting hidden states
with torch.no_grad():
    outputs = model(**inputs, output_hidden_states=True)

# Fetch top-layer hidden vector activations
last_hidden_state = outputs.hidden_states[-1]
print("GPT Last Hidden Layer Shape:", last_hidden_state.shape)

10. Modern Transformer Variants (RoBERTa, DeBERTa, T5)

Architectural iterations have refined Transformer embeddings further:
• RoBERTa: Optimizes BERT training by removing NSP, utilizing larger batches, and dynamic masking.
• DeBERTa: Disentangles attention matrices by decoupling content and relative position vectors.
• T5: Frames all NLP tasks into a unified text-to-text encoder-decoder framework.

Python (Hugging Face) deberta_t5_variant.py 
import torch
from transformers import AutoTokenizer, DebertaModel, T5EncoderModel

# 1. DeBERTa Disentangled Representation Extraction
deb_tokenizer = AutoTokenizer.from_pretrained("microsoft/deberta-v3-small")
deb_model = DebertaModel.from_pretrained("microsoft/deberta-v3-small")

deb_inputs = deb_tokenizer("DeBERTa decouples positioning from content.", return_tensors="pt")
with torch.no_grad():
    deb_out = deb_model(**deb_inputs)

print("DeBERTa Output Shape:", deb_out.last_hidden_state.shape)

# 2. T5 Unified Text-to-Text Encoder Extraction
t5_tokenizer = AutoTokenizer.from_pretrained("t5-small")
t5_encoder = T5EncoderModel.from_pretrained("t5-small")

t5_inputs = t5_tokenizer("summarize: Text-to-text representations", return_tensors="pt")
with torch.no_grad():
    t5_out = t5_encoder(**t5_inputs)

print("T5 Encoder Output Shape:", t5_out.last_hidden_state.shape)

High-Level Feature Extraction & Text Generation

While low-level PyTorch classes (AutoModelForCausalLM, AutoTokenizer) grant explicit control over attention maps and individual hidden layer tensors, Hugging Face's pipeline API provides an abstracted workflow for common NLP tasks:

  • Feature Extraction (feature-extraction): Directly extracts the final contextual hidden states (896-dimensional vectors per token for Qwen2.5-0.5B) without passing them through the classification/generation head. This is optimal for semantic search, document clustering, or vector database indexing.
  • Text Generation (text-generation): Runs an auto-regressive decoding loop that passes internal embeddings through the model's Causal Language Modeling head to predict and generate human-readable text.
Python (Hugging Face Pipelines) pipeline_embeddings_vs_generation.py 
from transformers import pipeline

# 1. Feature Extraction Pipeline (Extracts raw vector embeddings)
feature_extractor = pipeline(
    "feature-extraction", 
    model="Qwen/Qwen2.5-0.5B", 
    device_map="auto"
)
embeddings = feature_extractor("Neural networks learn representations by")
print("Extracted Embedding Dimension:", len(embeddings[0][0]))

# 2. Text Generation Pipeline (Converts internal embeddings into text)
generator = pipeline(
    "text-generation", 
    model="Qwen/Qwen2.5-0.5B", 
    torch_dtype="auto", 
    device_map="auto"
)
response = generator("Neural networks learn representations by", max_new_tokens=50)
print(response[0]['generated_text'])

# Expected Output:
# Extracted Embedding Dimension: 896
# Neural networks learn representations by adjusting internal weights through backpropagation...
